PawPal Android Lab Blueprint & Viva Guide

This blueprint matches the university Android Lab project syllabus requirements. Everything demonstrated in this website directly maps to native Java Android components.

1. Lab Syllabus Concepts & Implementation Map

  • Multiple Activities: SplashActivity, MainActivity, AddEditPetActivity, PetDetailsActivity, HealthActivity, DailyCareActivity, NearbyVetsActivity, SettingsActivity.
  • Explicit & Implicit Intents: Opening screens with extras, Camera/Gallery image picker intent, Dial vet intent (`ACTION_DIAL`), Share pet health record (`ACTION_SEND`).
  • SQLite Database & DAOs: `DatabaseHelper` extending `SQLiteOpenHelper` with ON DELETE CASCADE foreign keys. Separate DAO classes: `PetDao`, `FeedingDao`, `HealthRecordDao`, `CareLogDao`.
  • Notifications & Alarms: `NotificationChannel`, `AlarmManager` with `setExactAndAllowWhileIdle()`, and `ReminderReceiver` extending `BroadcastReceiver`.
  • Boot Receiver: `BootReceiver` listening for `ACTION_BOOT_COMPLETED` to reschedule alarms after device restart.
  • SharedPreferences: Saving dark mode preferences, notification toggles, and emergency vet contacts via `PrefsManager`.
  • Retrofit (Optional Online): `VetApiService` interface and `ApiClient` to fetch nearby vet clinics asynchronously.
  • Testing: JUnit unit tests for Date/Model utilities, and Espresso tests for UI workflows.

2. SQLite Database Schema

CREATE TABLE pets ( id INTEGER PRIMARY KEY AUTOINCREMENT, name TEXT NOT NULL, species TEXT NOT NULL, breed TEXT, age TEXT, weight REAL, photo_uri TEXT, notes TEXT ); CREATE TABLE feeding_schedule ( id INTEGER PRIMARY KEY AUTOINCREMENT, pet_id INTEGER NOT NULL, meal_name TEXT NOT NULL, time TEXT NOT NULL, instructions TEXT, enabled INTEGER DEFAULT 1, FOREIGN KEY(pet_id) REFERENCES pets(id) ON DELETE CASCADE ); CREATE TABLE health_records ( id INTEGER PRIMARY KEY AUTOINCREMENT, pet_id INTEGER NOT NULL, type TEXT NOT NULL, title TEXT NOT NULL, date TEXT NOT NULL, next_due_date TEXT, notes TEXT, FOREIGN KEY(pet_id) REFERENCES pets(id) ON DELETE CASCADE ); CREATE TABLE care_logs ( id INTEGER PRIMARY KEY AUTOINCREMENT, pet_id INTEGER NOT NULL, activity TEXT NOT NULL, date_time TEXT NOT NULL, completed INTEGER DEFAULT 1, FOREIGN KEY(pet_id) REFERENCES pets(id) ON DELETE CASCADE );
